# 💎 Sona钻石商店系统设计文档

## 📋 概述

Sona钻石商店是面向海外用户的内购系统，通过Google Play和Apple App Store提供钻石购买和订阅服务。钻石用于解锁应用内的高级功能，订阅提供持续的VIP服务和额外权益。

## 📱 支持的产品类型

### 1. 钻石商品 (Consumable - 消耗性)
- **购买方式**: 一次性购买，钻石可用于解锁各项功能
- **平台支持**: Google Play和Apple App Store
- **恢复购买**: 支持购买恢复（用户可在多设备间恢复购买）
- **退款政策**: 支持退款，Apple允许7天内退款
- **审核周期**: 相对较短（通常24-48小时）

### 2. 订阅服务 (Subscription - 订阅性)
- **购买方式**: 定期自动续费，提供持续VIP服务
- **平台支持**: Google Play和Apple App Store
- **恢复购买**: 自动处理订阅恢复，无需额外代码
- **退款政策**: 订阅退款处理较为复杂，由平台管理
- **审核周期**: 较长（通常2-5个工作日），需要详细说明订阅权益

## 🔍 App Store 订阅 vs 消耗性商品详细对比

| 特性 | 消耗性商品 (Consumable) | 订阅 (Subscription) |
|------|-------------------------|-------------------|
| **产品类型** | `consumable` | `auto-renewable subscription` |
| **购买模式** | 一次性购买 | 自动续费 |
| **用户体验** | 购买后立即消耗 | 持续服务，到期自动续费 |
| **恢复购买** | 需要手动实现恢复逻辑 | 平台自动处理 |
| **退款政策** | 支持7天内退款 | 退款由Apple管理，较复杂 |
| **审核要求** | 基础审核，重点检查商品描述 | 严格审核，需要详细权益说明 |
| **审核周期** | 24-48小时 | 2-5个工作日 |
| **定价策略** | 灵活，可随时调整 | 需提前规划价格矩阵 |
| **试用期** | 不支持 | 支持免费试用期 |
| **用户取消** | 无法取消（已购买） | 可随时取消自动续费 |
| **营收模式** | 一次性收入 | 持续性收入 |
| **数据统计** | 简单购买转化 | 复杂的订阅生命周期管理 |

## 🗄️ 数据库设计

### 钻石商品表 (diamond_product)
```sql
CREATE TABLE diamond_product (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id VARCHAR(50) UNIQUE NOT NULL,  -- diamond_200
    diamond_count INT NOT NULL,             -- 200
    price_usd DECIMAL(5,2) NOT NULL,        -- 0.49
    platform VARCHAR(20) DEFAULT 'all',     -- google, apple, all
    status INT DEFAULT 1,                   -- 1:启用 0:禁用
    sort_order INT DEFAULT 0,               -- 排序
    create_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_date DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 用户钻石账户表 (user_diamond)
```sql
CREATE TABLE user_diamond (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    diamond_count INT NOT NULL,             -- 钻石数量
    expire_date DATETIME,                   -- 过期时间，NULL表示永久
    source VARCHAR(50),                     -- 来源：purchase购买, reward奖励, gift赠送, consume消耗
    source_id VARCHAR(100),                 -- 来源关联ID
    create_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_expire_date (expire_date)
);
```

### 钻石交易记录表 (diamond_transaction)
```sql
CREATE TABLE diamond_transaction (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    transaction_type VARCHAR(20) NOT NULL,  -- purchase购买, consume消耗, expire过期, refund退款
    diamond_count INT NOT NULL,             -- 钻石数量变化（正数增加，负数减少）
    balance_before INT NOT NULL,            -- 变化前余额
    balance_after INT NOT NULL,             -- 变化后余额
    order_id VARCHAR(100),                  -- 关联订单ID
    product_id VARCHAR(50),                 -- 商品ID
    expire_date DATETIME,                   -- 钻石过期时间
    remark VARCHAR(200),                    -- 备注说明
    create_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_order_id (order_id),
    INDEX idx_create_date (create_date)
);
```

### 订阅商品表 (subscription_product)
```sql
CREATE TABLE subscription_product (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id VARCHAR(50) UNIQUE NOT NULL,  -- 1_month, 1_quarter等
    product_name VARCHAR(100) NOT NULL,      -- Astro Pair Plus Monthly
    duration_months INT NOT NULL,            -- 订阅月数
    price_usd DECIMAL(5,2) NOT NULL,         -- 价格
    daily_diamond_reward INT DEFAULT 0,      -- 每日钻石奖励
    platform VARCHAR(20) DEFAULT 'all',      -- google, apple, all
    status INT DEFAULT 1,                    -- 1:启用 0:禁用
    sort_order INT DEFAULT 0,                -- 排序
    create_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_date DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 用户订阅记录表 (user_subscription)
```sql
CREATE TABLE user_subscription (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    product_id VARCHAR(50) NOT NULL,          -- 订阅商品ID
    order_id VARCHAR(100) UNIQUE,             -- 平台订单ID
    subscription_id VARCHAR(100),             -- 订阅ID（用于续费验证）
    platform VARCHAR(20) NOT NULL,            -- google 或 apple
    status VARCHAR(20) DEFAULT 'active',      -- active, expired, cancelled
    start_date DATETIME NOT NULL,             -- 订阅开始时间
    end_date DATETIME NOT NULL,               -- 订阅结束时间
    auto_renew BOOLEAN DEFAULT TRUE,          -- 是否自动续费
    last_payment_date DATETIME,               -- 最后支付时间
    daily_reward_claimed_date DATE,           -- 最后领取每日奖励日期
    create_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_date DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_subscription_id (subscription_id),
    INDEX idx_end_date (end_date)
);
```

## 🔄 业务流程

### 内购流程
1. **用户选择商品** → 前端调用App Store/Google Play
2. **支付完成** → 获取收据数据
3. **发送到服务器** → POST /api/diamond/purchase 或 POST /api/subscription/purchase
4. **服务器验证收据** → 调用对应平台API验证
5. **验证成功** → 增加钻石余额或激活订阅
6. **记录交易** → 插入交易记录或订阅记录
7. **返回结果** → 通知前端支付成功

### 订阅业务流程

#### 初次订阅流程
1. **用户选择订阅套餐** → 前端调用平台订阅API
2. **支付成功** → 服务器接收订阅通知
3. **激活订阅** → 设置订阅状态和到期时间
4. **发放首次奖励** → 根据套餐发放钻石奖励
5. **设置自动续费** → 开启自动扣费服务

#### 自动续费流程
1. **到期前提醒** → 平台自动发送续费通知
2. **自动扣费** → 平台自动从用户账户扣费
3. **续费成功** → 服务器更新订阅到期时间
4. **发放续费奖励** → 发放续费钻石奖励

#### 每日奖励流程
1. **用户登录** → 检查订阅状态和奖励领取状态
2. **资格检查** → 确认订阅有效且未领取今日奖励
3. **发放奖励** → 增加钻石余额并记录领取状态
4. **更新状态** → 标记今日奖励已领取

### 消费流程
1. **用户使用功能** → 前端检查钻石余额
2. **钻石充足** → 调用消费接口
3. **扣除钻石** → 更新用户余额
4. **记录消费** → 插入消费记录
5. **返回结果** → 解锁功能

## 📊 数据统计

### 用户消费分析
- 平均每用户钻石持有量
- 钻石消耗转化率
- 各功能使用频率
- 付费用户占比

### 订阅用户分析
- 订阅转化率（试用用户转订阅）
- 订阅留存率（月度/季度/年度）
- 平均订阅时长
- 自动续费率
- 每日奖励领取率

### 收入分析
- **钻石销售**: 各商品销售占比
- **订阅收入**: 月度/年度订阅收入占比
- **ARPU**: 平均每用户收入 (钻石 + 订阅)
- **LTV**: 用户生命周期价值
- **付费渗透率**: 付费用户占比统计
- **退款率**: 钻石退款率 vs 订阅退款率
